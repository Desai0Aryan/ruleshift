# RULESHIFT Founder Pack

Starting package for building **RULESHIFT**, a mobile puzzle game where each player solves a short puzzle, changes one rule, and passes it to someone else.

## How to use this with Claude / Claude Code
1. Unzip this folder into an empty project directory.
2. Open Claude Code in that directory and say: "Read PLAN.md and everything in /docs, then start Phase 0."
3. Work phase by phase. Do not skip the Phase 1 validation gate.

## Honest caveats
- The market numbers and quotes in the research docs come from the earlier ChatGPT session. They were NOT independently re-verified here. Re-check any figure before relying on it.
- The original ChatGPT concept images were never delivered (image limit was hit) and the stock images shown in that chat belong to third parties, so they are not included. The SVGs in /assets are new, original sketches.
- Nobody can guarantee a game is unprecedented or will earn money. Competitor research (e.g. Baba Is You, Rollux, which were mentioned but never written up) must be done before committing.
